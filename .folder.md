# Python SDK root

| Path | Owner / role |
| --- | --- |
| AGENTS.md | Mandatory repository maintenance, validation and safety rules |
| CLAUDE.md | Complementary developer commands and source map |
| README.md | Public SDK installation and API entry guide |
| RELEASING.md | Authoritative downstream TestPyPI/PyPI promotion procedure |
| pyproject.toml | Distribution version, Python dependencies and portable archive membership |
| src/claude_agent_sdk/ | Upstream API and subprocess protocol; fixed import namespace |
| packaging/ | Provenance pin and hash-locked build inputs; README is the folder contract |
| docs/packaging/ | Integration/build documentation; README is the folder contract |
| scripts/ | Provenance, portable build, archive and installed-package verification |
| tests/ | SDK and packaging regression tests |
| e2e-tests/ | Explicit integration harness; no alternate production SDK |
| examples/ | SDK usage and session-store adapters, not Dream business persistence |
| .github/workflows/ | Read-only CI and separately protected portable publication |

Python SDK and npm Runtime are independent artifacts. This repository does not
contain Dream's thread/note mapping or shared database schema. Generated archives,
Runtime binaries, secrets and user workspaces are not repository inputs.
